# Refine Frontend

Apply the standard PromptForge refinement process with frontend-specific analysis focusing on component architecture, responsive behavior, accessibility, loading/error/empty states, and keyboard navigation.

## Usage

```
/refine-frontend <your request>
```

## Instructions

1. Follow the `/refine-build` process completely
2. Then apply the frontend lens from `promptforge/core/profiles/frontend.md`:
   - Component architecture and composition
   - Responsive behavior and breakpoints
   - Accessibility (WCAG compliance, keyboard nav, ARIA)
   - Loading states and optimistic updates
   - Error state handling
   - Empty state design
   - Keyboard navigation and focus management
   - Visual consistency and design system

3. Add frontend-specific sections to the Refined Implementation Prompt:
   - Component Architecture
   - Responsive Behavior
   - Accessibility Requirements
   - Loading States
   - Error States
   - Empty States
   - Keyboard Navigation
   - Visual Consistency

4. STOP — do not implement
5. Wait for `approve`
