# Refine Security

Apply the standard PromptForge refinement process with security-specific analysis focusing on authentication, authorization, input validation, secrets, privacy, abuse cases, rate limiting, and security testing.

## Usage

```
/refine-security <your request>
```

## Instructions

1. Follow the `/refine-build` process completely
2. Then apply the security lens from `promptforge/core/profiles/security.md`:
   - Authentication and authorization analysis
   - Trust boundary mapping
   - Input validation audit
   - Secrets inventory
   - Privacy assessment
   - Abuse case analysis
   - Dependency risk assessment
   - Security testing plan

3. Add security-specific sections to the Refined Implementation Prompt:
   - Authentication Requirements
   - Authorization Requirements
   - Trust Boundaries
   - Input Validation
   - Secrets Management
   - Privacy Considerations
   - Abuse Cases
   - Dependency Risk
   - Security Testing Plan

4. STOP — do not implement
5. Wait for `approve`
