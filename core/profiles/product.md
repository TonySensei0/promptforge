# Product Profile

Use this profile when the request involves user-facing features, product decisions, or MVP scoping.

## Additional Review Focus

Apply the base protocol first. Then apply these product-specific lenses:

### User Problem

- What is the actual problem the user is trying to solve?
- Is this a real pain point or a nice-to-have?
- Who experiences this problem and how often?
- What is the cost of not solving this problem?
- How do users currently work around this problem?

### User Stories

- Who are the primary users?
- Who are the secondary users (admins, moderators, observers)?
- What does each user type need to accomplish?
- What is the user's journey from problem to solution?
- Where are the friction points in the current workflow?

### MVP Scope

- What is the smallest version that delivers value?
- What must be included for the feature to be useful?
- What can be added in a follow-up iteration?
- What is the time-to-value for the user?
- What is the minimum lovable version?

### Success Metrics

- How will we know this feature is successful?
- What metrics indicate adoption?
- What metrics indicate the problem is solved?
- What metrics indicate the solution is working correctly?
- What is the target for each metric?

### Non-Goals

- What user segments are out of scope?
- What workflows are not addressed?
- What integrations are explicitly excluded?
- What "nice-to-have" features are deferred?
- What is the intentional tradeoff?

### UX Edge Cases

- What happens when the user makes a mistake?
- What happens when the user does nothing?
- What happens with extreme values (very long names, very large files)?
- What happens when multiple users interact simultaneously?
- What happens when the user loses connectivity mid-action?

## Product-Specific Open Questions

Add these questions when relevant:

- Who is the primary user persona?
- What is the user's technical proficiency level?
- What is the expected usage frequency?
- What competing solutions exist and how does this differentiate?
- What is the monetization or business model context?

## Product-Specific Non-Goals

Explicitly state:

- What user workflows are out of scope?
- What platforms or user segments are not targeted?
- What features are explicitly deferred to maintain simplicity?
